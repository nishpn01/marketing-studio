# Private business workspace template

**This template contains no real business facts.** Copy into an authorized private workspace (Google Drive or private repository) for each business. Never commit filled transcripts, client/customer data or confidential source material into the distributable core.

Suggested PARA-compatible organization:

```text
Business Marketing Workspace/
  00-START-HERE/       # Living directory + source authority map
  01-PROJECTS/         # Campaigns, newsletters, episodes, launch projects
  02-AREAS/            # Business, audience, brand, editorial programs, performance
  03-RESOURCES/        # References, approved stories, course notes, creative examples
  04-ARCHIVES/         # Completed work and superseded documents
  90-PRIVATE-INTAKE/   # Private transcripts, sensitive files requiring permission review
```

Each indexed file should have a stable identifier, title, status, owner, source link, last-reviewed date, permission class and related Linear issue.

For Drive: a live Google Doc or Markdown index is the primary directory; PDFs are optional snapshots and will get stale. Use links rather than duplicating authoritative source files. No automatic permission grants implied.

See `business.example.md` and `source-manifest.example.yaml`.
